# 🚗 Car Sales Data Analysis using Python

## 📌 Project Overview
This project focuses on analyzing car sales data to understand pricing trends, vehicle features, and manufacturer performance. Data cleaning, exploratory data analysis (EDA), and visualization techniques are used to extract meaningful insights from the dataset.

## 🛠️ Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📂 Dataset
The dataset contains information about different car models, manufacturers, prices, resale values, engine specifications, horsepower, fuel efficiency, and other vehicle attributes.

## 🔍 Analysis Performed
- Data cleaning and handling missing values
- Data type conversion and preprocessing
- Manufacturer-wise analysis
- Price distribution analysis
- Horsepower vs Price relationship analysis
- Resale value analysis
- Correlation analysis between numerical features
- Pivot table analysis

## 📊 Visualizations
The project includes:
- Price distribution histogram
- Horsepower vs Price scatter plot
- Manufacturer analysis charts
- Price and resale value comparison
- Unit sales analysis
- Correlation analysis charts

## 📈 Key Insights
- Horsepower shows a strong positive relationship with car price.
- Premium manufacturers have higher average car prices.
- Vehicle features impact pricing and resale value.
